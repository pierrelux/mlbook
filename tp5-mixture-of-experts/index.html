Partie 1: MoE vs GMM¶

Au TP3, le GMM modélise la densité des données p(x)p(\mathbf{x})p(x) par un mélange où les poids πk\pi_kπk​ sont constants (indépendants de x\mathbf{x}x):

p(x)=∑k=1Kπk N(x∣μk,Σk)p(\mathbf{x}) = \sum_{k=1}^K \pi_k \, \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)p(x)=k=1∑K​πk​N(x∣μk​,Σk​)
(1)

Le mélange d’experts (MoE) traite un problème supervisé: étant donné une entrée x\mathbf{x}x, prédire une sortie yyy. La différence clé: le réseau de routage gk(x)=p(z=k∣x)g_k(\mathbf{x}) = p(z=k \mid \mathbf{x})gk​(x)=p(z=k∣x) dépend de l’entrée. Chaque expert prédit p(y∣x,z=k)p(y \mid \mathbf{x}, z=k)p(y∣x,z=k).

p(y∣x)=∑k=1Kgk(x) p(y∣x,z=k)p(y \mid \mathbf{x}) = \sum_{k=1}^K g_k(\mathbf{x}) \, p(y \mid \mathbf{x}, z=k)p(y∣x)=k=1∑K​gk​(x)p(y∣x,z=k)
(2)

Les experts se spécialisent: chacun gère une région de l’espace d’entrée où il obtient les meilleurs résultats. Le réseau de routage apprend à assigner chaque x\mathbf{x}x à l’expert approprié.

Partie 3: Modèle MoE pour la régression¶

Nous utilisons un MoE avec:

  1. Routage (softmax): gk(x)=exp⁡(vk⊤x)∑j=1Kexp⁡(vj⊤x)g_k(\mathbf{x}) = \frac{\exp(\mathbf{v}_k^\top \mathbf{x})}{\sum_{j=1}^K \exp(\mathbf{v}_j^\top \mathbf{x})}gk​(x)=∑j=1K​exp(vj⊤​x)exp(vk⊤​x)​ — chaque expert reçoit un poids qui dépend de x\mathbf{x}x.

  2. Experts (régression linéaire gaussienne): p(y∣x,z=k)=N(y∣wk⊤x,σk2)p(y \mid \mathbf{x}, z=k) = \mathcal{N}(y \mid \mathbf{w}_k^\top \mathbf{x}, \sigma_k^2)p(y∣x,z=k)=N(y∣wk⊤​x,σk2​) — l’expert kkk prédit yyy par une droite.

La prédiction du modèle est une moyenne pondérée: y^=∑kgk(x) wk⊤x\hat{y} = \sum_k g_k(\mathbf{x}) \, \mathbf{w}_k^\top \mathbf{x}y^​=∑k​gk​(x)wk⊤​x.

def softmax_gating(X, V):
    logits = X @ V.T
    logits = logits - logits.max(axis=1, keepdims=True)
    exp_logits = np.exp(logits)
    g = exp_logits / exp_logits.sum(axis=1, keepdims=True)
    return g

def gaussian_pdf_1d(y, mu, sigma2):
    norm = 1.0 / np.sqrt(2 * np.pi * sigma2)
    return norm * np.exp(-0.5 * (y - mu) ** 2 / sigma2)

def moe_e_step(X, y, V, weights_list, sigmas):
    g = softmax_gating(X, V)
    mu = expert_predictions(X, weights_list, sigmas)

Exercice 4: Étape M — experts (régression pondérée) ★★¶

Pour chaque expert kkk, la mise à jour est une régression linéaire pondérée: on minimise ∑nrnk(yn−wk⊤xn)2\sum_n r_{nk} (y_n - \mathbf{w}_k^\top \mathbf{x}_n)^2∑n​rnk​(yn​−wk⊤​xn​)2.

La solution en forme fermée: wk=(X⊤RkX)−1X⊤Rky\mathbf{w}_k = (\mathbf{X}^\top \mathbf{R}_k \mathbf{X})^{-1} \mathbf{X}^\top \mathbf{R}_k \mathbf{y}wk​=(X⊤Rk​X)−1X⊤Rk​y, où Rk=diag(r1k,…,rNk)\mathbf{R}_k = \text{diag}(r_{1k}, \ldots, r_{Nk})Rk​=diag(r1k​,…,rNk​).

La variance: σk2=∑nrnk(yn−wk⊤xn)2∑nrnk\sigma_k^2 = \frac{\sum_n r_{nk} (y_n - \mathbf{w}_k^\top \mathbf{x}_n)^2}{\sum_n r_{nk}}σk2​=∑n​rnk​∑n​rnk​(yn​−wk⊤​xn​)2​

def moe_m_step_experts(X, y, responsibilities):
    N, D = X.shape
    K = responsibilities.shape[1]
    weights_list = []
    sigmas = np.zeros(K)

    for k in range(K):
        r_k = responsibilities[:, k]
        N_k = r_k.sum()
        X_r = np.sqrt(r_k)[:, np.newaxis] * X
        y_r = np.sqrt(r_k) * y
        w_k = np.linalg.lstsq(X_r, y_r, rcond=None)[0]
        weights_list.append(w_k)
        pred_k = X @ w_k
        sigmas[k] = np.sum(r_k * (y - pred_k) ** 2) / N_k + 1e-6

    return weights_list, sigmas

def moe_m_step_gating(X, responsibilities, V_init, n_steps=50, lr=0.1):

def moe_em(X, y, K=2, n_iterations=30, seed=42):
    """
    EM pour mélange d'experts.

    Returns:
        V, weights_list, sigmas: paramètres
        responsibilities: (N, K)
        log_likelihoods: liste
    """
    N, D = X.shape
    np.random.seed(seed)

    # Initialisation
    V = np.random.randn(K, D) * 0.1
    indices = np.random.choice(N, K, replace=False)
    weights_list = [np.linalg.lstsq(X, y, rcond=None)[0] + np.random.randn(D) * 0.1 for _ in range(K)]
    sigmas = np.ones(K) * 0.5

    log_likelihoods = []

    for t in range(n_iterations):
        # Étape E
        responsibilities = None  # <- moe_e_step(...)

        # Étape M
        weights_list, sigmas = None, None  # <- moe_m_step_experts(...)
        V = None  # <- moe_m_step_gating(...)

        # Log-vraisemblance
        g = softmax_gating(X, V)
        mu = expert_predictions(X, weights_list, sigmas)
        weighted_pdf = np.zeros(N)
        for k in range(K):
            weighted_pdf += g[:, k] * gaussian_pdf_1d(y, mu[:, k], sigmas[k])
        log_likelihoods.append(np.sum(np.log(weighted_pdf + 1e-10)))

    return V, weights_list, sigmas, responsibilities, log_likelihoods

def moe_em(X, y, K=2, n_iterations=30, seed=42):
    N, D = X.shape
    np.random.seed(seed)

    V = np.random.randn(K, D) * 0.1
    weights_list = [np.linalg.lstsq(X, y, rcond=None)[0] + np.random.randn(D) * 0.1 for _ in range(K)]
